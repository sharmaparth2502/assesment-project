# Old Codes

This folder contains older versions and previous copies of the code developed during the CABO Web Development Assessment.

These files are kept for reference and comparison with the current project. They are not part of the main working version of the website.

## Folder Structure

- `Codes` – Contains the initial code files.
- `new update code` – Contains an intermediate version of the project.
- `updated code` – Contains another updated version of the project.

**Note:** The main and latest project files are maintained in the root directory of the repository. This folder is only for reference.
