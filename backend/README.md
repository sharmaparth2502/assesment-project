
# CABO Backend

This folder contains the backend development files for the CABO platform.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose

## Features (Planned)

- Buyer and seller data management
- User registration and login APIs
- Carbon credit data management
- MongoDB database connectivity

## Configuration

The `.env.example` file contains the environment variables required for the backend.

A separate `.env` file will be used for actual configuration and should not be uploaded to GitHub.

## Server

The backend server is configured to run on port 5000 by default.
